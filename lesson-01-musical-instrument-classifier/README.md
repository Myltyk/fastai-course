# Musical Instrument Classifier — Fast.ai Lesson 1

My first computer vision project following **Fast.ai Lesson 1**.

I adapted the original "Is it a bird?" exercise to classify three musical instruments:

* Dombra
* Guitar
* Violin

The model is built using **Fast.ai** and **ResNet34** with transfer learning.
